# BookNest – Community Book Exchange
Flask + SQLite web app (Web Application Development Lab final project).

## Run
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000 (the database and demo data are created automatically).

## Features
Landing page, register/login/logout, roles (member, admin), book CRUD, search + category + availability filter,
borrow-request workflow (request, approve, decline, return, cancel), dashboard, profile, admin panel with reports,
responsive design, hashed passwords, ownership/role checks.
